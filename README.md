# Сайт факультету

Сайт факультету природничих наук

## Чому природничі?

Тому що, у них не було свого сайту, так само як у ФГН, проте цей факультет менший, 
тому обрав його, також інформація розкидана та інколи суперечить сама собі, і це 
спроба це трішки виправити. 
Інформацію брав зі вступу та зі старих архівів

## Сетап

1. python -m venv .venv
2. pip install -r requirements-dev.txt
3. python manage.py migrate
4. python manage.py loaddata filled_data
5. python manage.py createsuperuser
6. python manage.py runserver

## Сторінки
`/` - Головна сторінка

На цій сторінці міститься опис факультету, основна інформація, контакти.

`/programs/` - Список спеціальностей

Про кожну спеціальність виведено назву, код, короткий опис (перші 50 слів 
опису), імʼя та контакт координатора набору.

Натискання на назву спеціальності перенадсилає на сторінку цієї спеціальності.

`/programs/<id>/` - Сторінка спеціальності

Тут крім перечислених вище полів розміщено повну версію опису та список дисциплін, що 
вивчається.

`/departments/` - Список кафедр

Про кожну кафедру виведено назву, завідувача кафедри та список спеціальностей для 
яких ця кафедра є випусковою. При натисканні на назву кафедри - перенадсилає на сторінку кафедри.

`/departments/<id>/` - Сторінка окремої кафедри

Крім вже згаданої інформації тут також міститься список викладачів. Про кожного 
викладача виведено імʼя та його посаду і науковий ступінь.

`/exchange/` - Сторінка програм обміну

Тут вся друга частина лаби, з відображенням назви університету, країни, опису, дедлайну,
та кількістю слотів програми
